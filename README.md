# MapNotes

MapNotes is a mobile application built with **React Native and Expo**. It allows users to save locations on an interactive map and attach personal notes to them.

The project was developed as part of **Mandatory I – React Native** at KEA.

## Features

- Interactive Google Maps integration
- Display the user's current location
- Create map markers by long-pressing the map
- Add titles and notes to markers
- View, edit and delete existing markers
- Select images from the gallery or take photos using the camera
- Anonymous authentication with Firebase
- Persistent marker and note storage using Cloud Firestore
- Real-time updates using Firestore listeners

## Technologies

- React Native
- Expo
- JavaScript
- react-native-maps
- expo-location
- expo-image-picker
- Firebase Authentication
- Cloud Firestore
